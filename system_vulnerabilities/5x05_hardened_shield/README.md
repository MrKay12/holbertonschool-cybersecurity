# 5x05 - Hardened Shield

> A production-ready, hardened container image for NovaTech Solutions:
> Nginx + OpenSSH on Ubuntu 22.04 LTS, locked down at build time, re-checked
> at every start and verified by an automated audit.

## Project Description

NovaTech Solutions needs one trusted base image for its web deployments.
**Hardened Shield** is the capstone of the *System Vulnerabilities* module.
It combines the earlier projects into a single image:

| Project | Contribution |
|---|---|
| **5x01** | Patching: security updates applied at build, minimal packages |
| **5x02** | System hardening: kernel parameters, filesystem permissions, service minimization, SUID/SGID removal, legal banner |
| **5x03** | Identity and access: PAM password policy, account lockout, key-only SSH, root lockdown, optional MFA |
| **5x04** | Container security: non-root web server, dropped capabilities, no-new-privileges, read-only root, resource limits |

The image serves a static website with **Nginx running entirely as a
non-root user**, and offers **key-only SSH** for administration. It contains
no secrets. Every control is applied at build time, verified again when the
container starts (a non-compliant container refuses to start), and measured
by `audit.py`, which produces a scored report.

**Latest audit:** ✅ **PASS, 97.1 %**: 101 controls, 0 critical failures
(see [`audit_result.md`](audit_result.md)).

## Quick Start

You need Docker with Compose v2 and an SSH key pair.

**1.** Go to the project directory:

```bash
cd system_vulnerabilities/5x05_hardened_shield
```

**2.** Give the admin public key. It is read at runtime and never stored in
the image:

```bash
export SSH_ADMIN_PUBKEY="$(cat ~/.ssh/id_ed25519.pub)"
```

**3.** Build and start:

```bash
docker compose up -d --build
```

**4.** Wait for `healthy` (about 10 s):

```bash
docker compose ps
```

**5.** Use it:

```bash
curl -I http://localhost/
```

```bash
ssh sysadmin@localhost
```

```bash
docker compose exec shield audit.py
```

**6.** Stop:

```bash
docker compose down
```

## Build and Run Instructions

### Build

With Compose:

```bash
docker compose build
```

Or with Docker directly, recording the build date and git revision in the
image labels:

```bash
docker build -t novatech/hardened-shield:1.0.0 --build-arg BUILD_DATE="$(date -u +%Y-%m-%dT%H:%M:%SZ)" --build-arg VCS_REF="$(git rev-parse --short HEAD)" .
```

The build runs `init-hardening.sh --build` and `init-identity.sh --build`,
and fails if either one fails. Check the size (it must stay under 500 MB):

```bash
docker images novatech/hardened-shield
```

### Run with Compose (recommended)

`docker-compose.yml` applies the full secure runtime profile:

```bash
docker compose up -d
```

| Setting | Value |
|---|---|
| Ports | `80 → 8080` (web), `22 → 22` (SSH; `SSH_HOST_PORT=2222` if the host already runs sshd) |
| Capabilities | `cap_drop: ALL` + CHOWN, SETUID, SETGID, SYS_CHROOT, NET_BIND_SERVICE, KILL |
| Security options | `no-new-privileges:true`, AppArmor `docker-default`, default seccomp, `read_only: true` |
| Resources | 1 CPU, 512 MB memory (no swap), 200 processes |
| Volumes | `ssh-hostkeys` → `/var/lib/ssh-hostkeys`, `logs` → `/var/log`; tmpfs `noexec,nosuid,nodev` for `/tmp`, `/run`, `/var/lib/nginx`, `/var/lib/fail2ban` |

### Run with `docker run`

Equivalent hardened command:

```bash
docker run -d --name hardened-shield -p 80:8080 -p 22:22 --cap-drop=ALL --cap-add=CHOWN --cap-add=SETUID --cap-add=SETGID --cap-add=SYS_CHROOT --cap-add=NET_BIND_SERVICE --cap-add=KILL --security-opt no-new-privileges:true --read-only --tmpfs /tmp:rw,noexec,nosuid,nodev --tmpfs /run:rw,noexec,nosuid,nodev --tmpfs /var/lib/nginx:rw,noexec,nosuid,nodev --tmpfs /var/lib/fail2ban:rw,noexec,nosuid,nodev -v ssh-hostkeys:/var/lib/ssh-hostkeys -v shield-logs:/var/log --memory 512m --memory-swap 512m --cpus 1 --pids-limit 200 -e SSH_ADMIN_PUBKEY="$SSH_ADMIN_PUBKEY" novatech/hardened-shield:1.0.0
```

### Configuration

| Variable | Default | Purpose |
|---|---|---|
| `SSH_ADMIN_PUBKEY` | - | Admin public key(s): ed25519, ecdsa or RSA ≥ 3072 |
| `SSH_ADMIN_PUBKEY_FILE` | `/run/secrets/ssh_admin_pubkey` | Same, from a file or Docker secret |
| `MFA_ENABLED` | `false` | `true` = public key + TOTP (refuses to start without a seed) |
| `SSH_ADMIN_TOTP_FILE` | `/run/secrets/ssh_admin_totp` | `google-authenticator` file for `sysadmin` |
| `SSH_HOSTKEY_DIR` | `/var/lib/ssh-hostkeys` | Persistent SSH host keys |
| `FAIL2BAN_ENABLED` | `auto` (`false` in compose) | `auto` starts fail2ban when iptables works (needs `NET_ADMIN`, `NET_RAW`) |
| `STRICT_HARDENING` | `false` | `true` = runtime hardening warnings stop the container |

### Operate and audit

| Task | Command |
|---|---|
| Service status | `docker compose exec shield init-services.sh --status` |
| Compliance check (no changes) | `docker compose exec shield init-hardening.sh --check` |
| Identity check (no changes) | `docker compose exec shield init-identity.sh --check` |
| Full audit (console) | `docker compose exec shield audit.py` |
| Audit report | `docker compose exec shield audit.py -q -o /tmp/audit_result.md` then `docker compose cp shield:/tmp/audit_result.md .` |
| JSON for CI | `docker compose exec shield audit.py -q --json -` |
| Logs | `docker compose logs -f shield` |
| Integration validation (host) | `scripts/integration-test.sh` (`--down` to stop after, `--save-report` to refresh `audit_result.md`) |

## Security Features Summary

| Domain | Features |
|---|---|
| **Kernel** | 17 network sysctls: no IP forwarding, ICMP redirects or source routing; reverse-path filtering, SYN cookies, martian logging. Host-level `kernel.*` values documented |
| **Filesystem** | Read-only root, `noexec,nosuid,nodev` tmpfs, strict permissions on `shadow`/`passwd`/`sshd_config`, no world-writable files, **no SUID/SGID binaries**, no core dumps, umask 027 |
| **Services** | Only Nginx and sshd; telnet, ftp, rsh, inetd, cron/at, netcat, nmap and compilers removed; forbidden daemons blocked |
| **Identity** | Passwords: 12+ characters, 4 classes, history 5, aging 90 days. Lockout: 5 failures → 15 min (root too). Root: password locked, `su` restricted, idle timeout |
| **SSH** | Public key only (+ optional TOTP), no root login, `AllowGroups sshusers`, `MaxAuthTries 3`, modern ciphers/KEX/MACs, DH ≥ 3072, no forwarding, legal banner, verbose logging, host keys generated at runtime |
| **Web** | Nginx master and workers as `appuser` (no root process), version hidden, security headers (CSP, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy), GET/HEAD only, dotfiles blocked, rate limit 10 req/s per IP |
| **Container** | Minimal LTS base, updates applied, **no secrets**, `cap_drop: ALL` + 6, no-new-privileges, seccomp, AppArmor, CPU/memory/PID limits, isolated network, tini as PID 1, HEALTHCHECK, OCI labels, ~180 MB |
| **Verification** | Idempotent scripts with `--check` modes, start-time re-verification (fail closed), automated audit with per-category scores and an overall PASS/FAIL |
