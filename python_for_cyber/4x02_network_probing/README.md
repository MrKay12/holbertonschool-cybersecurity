# 4x02 - Network Probing

NetProbe is a Python network probing tool built step by step.

## Setup

    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt

    cd holbertonschool-cybersecurity
    mkdir -p python_for_cyber/4x02_network_probing
    cd python_for_cyber/4x02_network_probing
    python3 -m venv venv

## Usage

    ./net_probe.py
